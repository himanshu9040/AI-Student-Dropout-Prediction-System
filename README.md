# AI-Based Student Dropout Prediction and Counselling System

A web-based project focused on student dropout prediction and counselling support.

## Project Overview

This project presents an AI-based approach for identifying students who may be at risk of dropping out. It is intended to support early intervention, guidance, and counselling for students.

## Files in This Repository

- `index.html` — Main web page of the project
- `AI BASED DROPOUT PREDICTION SYSTEM.pdf` — Project report/documentation
- `AI BASED DROPOUT PREDICTION SYSTEM.pptx` — Project presentation

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
